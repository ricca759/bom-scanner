# Nokia 3210 Snake (Web)

A retro-styled Snake game inspired by the classic Nokia 3210 experience.

## Play

1. Open `index.html` in a browser.
2. Press **●** (or `Enter`/`Space`) to start.
3. Use arrow keys or on-screen controls to move.
4. Eat food to grow and increase score.
5. Avoid walls and your own tail.

## Features

- Nokia-style monochrome visual theme
- Keyboard + touch controls
- Local high score saved in browser (`localStorage`)
- Single-file app (easy to deploy to GitHub Pages)
